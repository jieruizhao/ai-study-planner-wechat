# 架构与设计

项目使用原生微信页面、云函数模块化单体、云数据库和 Coze 工作流。前端管理交互与用户确认；`api` 从可信微信上下文获取 OPENID，按账号限定读写范围，不信任请求体中的用户身份。

## AI 学习闭环

1. 选择最近 7 天、30 天或自定义区间，服务端汇总学习时长、活跃日、科目、任务与习惯完成情况。
2. 用户明确同意后，传递统计和截取后的学习记录；不发送头像、昵称或账号标识。
3. 导师提示词要求区分事实和推测、引用统计、尊重可学习日与时间预算。
4. 服务端校验模型 JSON、日期、字段长度、时长与预算，保存分析。
5. 用户编辑预览并确认导入。确定性批次 ID 和事务保障重复请求不重复创建计划。
6. 撤销仅移除未使用且未修改的建议，保留完成任务、学习记录和已修改项。

历史删除使用删除标记。导入历史展示删除后保留批次及防重信息，避免已撤销报告重新导入。删除历史不等同于撤销计划。

## 失败处理

普通网络失败与模型拒绝调用分别提示。模型请求等待窗口为 45 秒，`api` 等待 `studyAgent` 设置为 55 秒；函数执行上限建议 60 秒。客户端传输超时不能证明后端失败，因此先尝试恢复本次已保存分析，不自动重复调用模型。

云端 SDK 对不存在文档的行为可能不同；仅明确的文档不存在错误视为空值，权限或网络错误继续抛出。事务写入使用文档引用中的 ID，写入内容不包含保留字段 `_id`。

## 局限

习惯预期次数依据当前配置估算，不还原未保存的历史规则。AI 输入按数量与文本预算截取，页面说明材料范围。微信订阅额度和系统通知受平台及用户设置约束。本地模拟测试不等于所有设备、云端权限和真实模型输出都已验证。
